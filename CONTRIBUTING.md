# // contributing //

thanks for helping improve this landing page.

## // workflow //

- open an issue for bugs or enhancement ideas
- keep changes focused and minimal
- do not commit secrets or credentials
- preserve the existing site aesthetic and avoid disruptive redesigns

## // pull requests //

- describe what changed and why
- include screenshots for visual changes
- ensure workflows pass before requesting review

## // palette //

to preserve the existing visual tone, prefer the established color system:

- `#000000`
- `#00E5FF`
- `#7DF9FF`
- `#FF6B00`
- `#FFFFFF`
